# Plan V3-4: Graph ops (selection, history, clipboard, persistence, delete)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Full document manipulation API on the controller: granular node/edge ops, selection ops, undo/redo, clipboard, save/load, delete-with-cascade.

**Architecture:** All mutations go through `LatticeDocumentController` verbs that (a) apply O(delta) map updates, (b) push the pre-image onto `LatticeHistoryController` (document snapshots, coalesced per frame for drags), (c) notify controller listeners once. Clipboard holds serialized node/edge payloads + paste offset. Session-only writes (hover, marquee ticks) never touch history.

**Tech Stack:** Flutter, flutter_riverpod, widget + unit tests.

**Spec:** `docs/superpowers/specs/2026-10-12-lattice-rewrite-design.md` (§3.1, §5 item 2)

## Global Constraints
- SDK `^3.10.0`, Flutter `>=3.35.0`; deps flutter + flutter_riverpod only; no codegen.
- TDD + commit per task. `lib/src/v3/` only; no `lib/lattice.dart` change.

## Review Focus
- Undo after 60 rapid marquee ops → history bounded (cap 100), no memory blowup. Pinned in Task 2.
- Delete node with edges + children → edges pruned, descendants removed, one undo restores all. Pinned in Task 4.
- Paste with id collision → fresh ids assigned, edges rewired to new ids. Pinned in Task 3.
- `load()` replaces document → selection cleared, history reset, one notification. Pinned in Task 1.
- Node with `deletable: false` survives `deleteSelection`. Pinned in Task 4.
