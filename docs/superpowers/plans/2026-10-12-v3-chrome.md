# Plan V3-6: Chrome (minimap, resizer, toolbar, panels, background, keyboard, a11y, dataflow, theme)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** All remaining features on the new core: minimap, node resizer, toolbar/controls, panels, background, keyboard shortcuts, accessibility, dataflow selectors, and the final `LatticeTheme` / extended `LatticeOptions` / `LatticeCallbacks`.

**Architecture:** Every chrome widget is a plain `ConsumerWidget` over the public selectors — no new state systems. Minimap reuses `LatticeLodPainter`. Resizer is a selection-overlay drag handled by the gesture router. Keyboard acts through controller verbs. A11y comes free (nodes stay widgets) + a live-region announcer on selection/connection events.

**Tech Stack:** Flutter, flutter_riverpod, widget tests (semantics tests for a11y).

**Spec:** `docs/superpowers/specs/2026-10-12-lattice-rewrite-design.md` (§5 items 4–5, §4)

## Global Constraints
- SDK `^3.10.0`, Flutter `>=3.35.0`; deps flutter + flutter_riverpod only; no codegen.
- TDD + commit per task. `lib/src/v3/` only; no `lib/lattice.dart` change.

## Review Focus
- Minimap with 2500 nodes → paints in one frame, never mounts node widgets. Pinned in Task 1.
- Resize below minSize → clamped, and undo restores pre-resize size. Pinned in Task 2.
- Keyboard Delete with empty selection → no-op, no history entry, no crash. Pinned in Task 4.
- Screen reader traverses nodes in z-order with labels (id fallback). Pinned in Task 5.
- Partial theme override (only node border) → all other theme values intact. Pinned in Task 6.
